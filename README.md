# Snake-game
**Проект: Реализация игры "Змейка"**

**Описание проекта:**
Целью данного проекта является создание консольной версии игры "Змейка". Игра будет имитировать классическую змейку, где игрок управляет змейкой, собирая еду и увеличивая свой размер, при этом избегая столкновений со стенами или самим собой.

**Реализуемый функционал:**
1. Создание игрового поля (поля для змейки и еды).
2. Управление змейкой с помощью клавиш на клавиатуре.
3. Генерация еды на поле и увеличение длины змейки при съедании.
4. Проверка на столкновение змейки со стенами или самой собой.
5. Подсчет и вывод очков игрока.
6. Обработка конца игры при достижении условий поражения.

**Архитектура:**
1. **Класс SnakeGame:**
   - Методы:
     - start_game(): начинает игру и управляет основным циклом игры.
     - end_game(): завершает игру и выводит результаты игры.
   - Атрибуты:
     - board: объект класса Board, представляющий игровое поле.
     - snake: объект класса Snake, представляющий змейку.
     - food: объект класса Food, представляющий еду.

2. **Класс Board:**
   - Методы:
     - create_board(): создает игровое поле с заданными размерами.
     - draw_board(): отображает игровое поле с текущим состоянием змейки и еды.
   - Атрибуты:
     - board_state: двумерный массив, представляющий состояние игрового поля.

3. **Класс Snake:**
   - Методы:
     - move(direction): перемещает змейку в заданном направлении.
     - check_collision(): проверяет столкновения змейки со стенами или самой собой.
     - eat_food(): увеличивает длину змейки при поедании еды.
   - Атрибуты:
     - body: список координат, представляющих тело змейки.
     - direction: текущее направление движения змейки.

4. **Класс Food:**
   - Методы:
     - generate_food(): генерирует новую позицию для еды на игровом поле.
   - Атрибуты:
     - position: координаты текущего положения еды на поле.
