# Змейка - проектная документация (обновленная)

## Описание проекта
Цель данного проекта - создание расширенной версии игры "Змейка" с использованием языка программирования Python и библиотеки Pygame. В игре будут добавлены новые возможности, такие как несколько уровней сложности, различные виды бонусов, таблица рекордов и ускорение движения змейки по ходу времени.

## Реализуемый функционал
1. Создание игрового поля с отображением змейки, еды и различных видов бонусов.
2. Управление змейкой с помощью клавиш клавиатуры (вверх, вниз, влево, вправо).
3. Генерация случайным образом еды и бонусов на поле.
4. Проверка столкновений змейки с границами поля, самой собой и другими объектами (еда, бонусы).
5. Увеличение длины змейки при съедании еды.
6. Различные виды бонусов, которые могут влиять на игровой процесс (например, ускорение змейки, увеличение очков).
7. Несколько уровней сложности игры с различными скоростями движения змейки.
8. Таблица рекордов для отслеживания лучших результатов игроков.
9. Ускорение движения змейки по мере увеличения времени игры.

## Архитектура
### Классы
1. **Game** - основной класс игры, который будет отвечать за инициализацию игры, обновление экрана, обработку событий и управление игровым циклом.
   - Методы:
     - __init__() - инициализация игры.
     - run() - запуск игрового цикла.
     - handle_events() - обработка событий (например, нажатия клавиш).
     - update() - обновление состояния игры.
     - draw() - отрисовка элементов на экране.
  
2. **Snake** - класс для представления змейки на игровом поле.
   - Атрибуты:
     - body - список координат сегментов змейки.
     - direction - текущее направление движения змейки.
   - Методы:
     - move() - перемещение змейки в заданном направлении.
     - eat_food() - увеличение длины змейки при съедании еды.
     - check_collision() - проверка столкновений змейки с границами поля, самой собой и другими объектами.
     
3. **Food** - класс для представления еды на игровом поле.
   - Атрибуты:
     - position - координаты позиции еды на поле.
   - Методы:
     - generate_position() - генерация новой позиции для еды.

4. **Bonus** - класс для представления бонусов на игровом поле.
   - Атрибуты:
     - position - координаты позиции бонуса на поле.
     - type - тип бонуса (например, ускорение).
   - Методы:
     - generate_position() - генерация новой позиции для бонуса.
  
5. **Leaderboard** - класс для работы с таблицей рекордов.
   - Методы:
     - load_scores() - загрузка рекордов из файла.
     - update_score() - обновление таблицы рекордов с новым результатом.
     - display_scores() - отображение таблицы рекордов на экране.

## Дополнительные функции
1. **check_collision_with_bonus()** - проверка столкновения змейки с бонусами.
2. **update_score()** - обновление текущего счета и лучшего результата.
3. **increase_speed()** - ускорение движения змейки по ходу времени.
